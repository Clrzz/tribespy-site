Get started

Ready in 3 steps

Requires the “Manage Server” permission.

  1. Add the bot

    Click “Add to Discord” and pick your server.

  2. Pick a channel

    Type /config channels to choose where the dashboard is displayed.

  3. Add your servers

    Type /config add-server with a name, the IP and the query port. The bot checks that it responds.

Commands

All commands

For everyone

/history
Last connection of a player on each map, or who played on a given map.
/info
A player's playtime, map by map.
/stats
Key numbers for your Discord server.
/help
The list of commands.

For admins

/config
Channels, time zone, language, adding and removing game servers, configuration status.
/blacklist
Add, remove or list watched players.
/tribe
Link a player to a tribe, shown next to their name.
/data
Erase a player's data, or the whole history.

FAQ

Frequently asked questions

Which games are supported?

TribeSpy uses the Steam query protocol (A2S). It is built and tested for ARK: Survival Evolved. Other games using this protocol may work, with no guarantee.

Which port should I enter?

Your server's query port, which is often different from the game port. If the bot can't reach it, it tells you when you add the server.

Does the bot read our messages?

No. It has no access to messages or to the member list. It only writes in the channels you choose.

Can I use the bot in French?

Yes. Run /config language and choose Français. The language is set per Discord server.

Is it really free?

Yes. All features are free for now. If paid options ever appear, the free features you use today will stay free.

Privacy

Your data

A plain-language summary. To be reviewed by a legal professional before the public launch.

What is stored

  • In-game names, maps, last connection time and playtime.
  • Your configuration: channels, game servers, blacklist and tribes.
  • Nothing else: no messages, no Discord members, no payment data.
  • Each Discord server only sees its own data.

Retention and rights

  • 180 days: old data is deleted automatically.
  • Erasure: /data delete-player or /data reset.
  • If the bot leaves: data is deleted after 30 days.

Setup guide

Set up TribeSpy in 2 minutes

You've added the bot to your Discord server? Great. Follow the steps below, there are only four of them.

Before you start

  • You need the Manage Server permission on the Discord server (the owner and admins have it).
  • Have your game server's IP and query port ready. You'll find them in your host's panel.

Pick one way

  1. Open the configuration page

    Click Configuration at the top right of the website, or the Configure on the website button in the bot's welcome message on Discord.

    Open Configuration

  2. Log in with Discord

    Click Log in with Discord, then Authorize on the Discord page. We only see your name and your server list.

    Your servers show up. Click Configure next to the one where you added the bot.

    You see Add the bot instead of Configure? The bot isn't on that server yet: click it to add it, then come back and click Refresh the list.

  3. Choose the channels, time zone and language

    In the General tab:

    • Dashboard channel: where the list of online players will be shown. A dedicated channel like #players-online is ideal.
    • History channel (optional): connections, outage alerts, blacklist alerts and recaps.
    • Time zone: start typing your city (e.g. Europe/London) and pick it in the list.
    • Bot language: English or Français.

    Click Save. A green message confirms each setting.

    A channel shows (missing permissions)? In Discord, give the bot View Channel, Send Messages and Embed Links in that channel.

  4. Add your game server

    In the Game servers tab, fill in:

    • Display name: the name shown on Discord, e.g. Ragnarok.
    • Address: IP:query port, e.g. 151.242.127.127:27018.

    Click Add. The bot checks right away that the server responds. Repeat for each map of your cluster.

    ✔ Done! The dashboard appears in your channel within a minute.

  1. Choose the channels

    In any channel, type /config channels, then pick the dashboard channel. You can also add a history channel for alerts and recaps (optional).

    /config channelsdashboard: #players-onlinehistory: #tribespy-logs
    ✅ Dashboard: #players-online
    ✅ History: #tribespy-logs

  2. Add your game server

    Type /config add-server, give it a name and the address as IP:query port. Repeat for each map.

    /config add-servername: Ragnarokaddress: 151.242.127.127:27018
    ✅ Ragnarok added — server reachable (12/70 players).

  3. Set your time zone

    Type /config timezone, start typing your city (e.g. Europe/Lon) and pick it in the suggestions. Times and recaps will use it.

  4. Pick the language and check

    /config language switches the bot to English or Français. Then type /config status: everything should be green.

    ✔ Done! The dashboard appears in your channel within a minute.

Going further

Watch players with the blacklist

Website: Blacklist tab. Discord: /blacklist add with the exact player name. You get an alert in the history channel when they connect, and a raid alert if 3 of them show up on the same map within 5 minutes.

Show tribes next to player names

Website: Tribes tab. Discord: /tribe set with the player and the tribe. The tribe shows up in brackets on the dashboard.

The bot says my server isn't responding
  • Make sure you used the query port, not the game port. On ARK it's often 27015 or close to it.
  • Use the public IP (or domain) of the server, never a local one like 192.168.x.x.
  • Check that the server is online and that its firewall lets queries through.
  • The server stays added: the bot will pick it up as soon as it responds.
Nothing shows up in my channel

Type /config status. If a channel shows "missing permissions", give the bot View Channel, Send Messages and Embed Links in it. The dashboard refreshes every minute.

Configurer TribeSpy en 2 minutes

Vous avez ajouté le bot à votre serveur Discord ? Parfait. Suivez les étapes ci-dessous, il n'y en a que quatre.

Avant de commencer

  • Il faut la permission Gérer le serveur sur le serveur Discord (le propriétaire et les admins l'ont).
  • Gardez sous la main l'IP et le port de requête (query port) de votre serveur de jeu. Ils sont dans le panel de votre hébergeur.

Choisissez une méthode

  1. Ouvrez la page Configuration

    Cliquez sur Configuration en haut à droite du site, ou sur le bouton Configurer sur le site du message de bienvenue du bot sur Discord.

    Ouvrir la Configuration

  2. Connectez-vous avec Discord

    Cliquez sur Se connecter avec Discord, puis sur Autoriser sur la page de Discord. On voit seulement votre nom et la liste de vos serveurs.

    Vos serveurs s'affichent. Cliquez sur Configurer à côté de celui où vous avez ajouté le bot.

    Vous voyez Ajouter le bot au lieu de Configurer ? Le bot n'est pas encore sur ce serveur : cliquez dessus pour l'ajouter, revenez puis cliquez sur Actualiser la liste.

  3. Choisissez les salons, le fuseau et la langue

    Dans l'onglet Général :

    • Salon du tableau de bord : là où s'affiche la liste des joueurs en ligne. Un salon dédié comme #joueurs-en-ligne est idéal.
    • Salon d'historique (facultatif) : connexions, alertes de panne, alertes blacklist et bilans.
    • Fuseau horaire : commencez à taper votre ville (ex. Europe/Paris) et choisissez-la dans la liste.
    • Langue du bot : English ou Français.

    Cliquez sur Enregistrer. Un message vert confirme chaque réglage.

    Un salon affiche (droits manquants) ? Dans Discord, donnez au bot Voir le salon, Envoyer des messages et Intégrer des liens dans ce salon.

  4. Ajoutez votre serveur de jeu

    Dans l'onglet Serveurs de jeu, remplissez :

    • Nom affiché : le nom qu'on verra sur Discord, ex. Ragnarok.
    • Adresse : IP:port de requête, ex. 151.242.127.127:27018.

    Cliquez sur Ajouter. Le bot vérifie tout de suite que le serveur répond. Recommencez pour chaque map de votre cluster.

    ✔ C'est fini ! Le tableau de bord apparaît dans votre salon en moins d'une minute.

  1. Choisissez les salons

    Dans n'importe quel salon, tapez /config channels, puis choisissez le salon du tableau de bord. Vous pouvez aussi ajouter un salon d'historique pour les alertes et les bilans (facultatif).

    /config channelsdashboard: #joueurs-en-lignehistory: #tribespy-logs
    ✅ Tableau de bord : #joueurs-en-ligne
    ✅ Historique : #tribespy-logs

  2. Ajoutez votre serveur de jeu

    Tapez /config add-server, donnez un nom et l'adresse sous la forme IP:port de requête. Recommencez pour chaque map.

    /config add-servername: Ragnarokaddress: 151.242.127.127:27018
    ✅ Ragnarok ajouté — serveur joignable (12/70 joueurs).

  3. Réglez le fuseau horaire

    Tapez /config timezone, commencez à taper votre ville (ex. Europe/Par) et choisissez-la dans les suggestions. Les heures et les bilans l'utiliseront.

  4. Choisissez la langue et vérifiez

    /config language passe le bot en Français ou en English. Tapez ensuite /config status : tout doit être au vert.

    ✔ C'est fini ! Le tableau de bord apparaît dans votre salon en moins d'une minute.

Pour aller plus loin

Surveiller des joueurs avec la blacklist

Site : onglet Blacklist. Discord : /blacklist add avec le nom exact du joueur. Une alerte arrive dans le salon d'historique quand il se connecte, et une alerte raid si 3 joueurs surveillés arrivent sur la même map en 5 minutes.

Afficher les tribus à côté des joueurs

Site : onglet Tribus. Discord : /tribe set avec le joueur et la tribu. La tribu s'affiche entre crochets sur le tableau de bord.

Le bot dit que mon serveur ne répond pas
  • Vérifiez que vous avez mis le port de requête et pas le port de jeu. Sur ARK, c'est souvent 27015 ou un port proche.
  • Utilisez l'IP publique (ou le domaine) du serveur, jamais une IP locale comme 192.168.x.x.
  • Vérifiez que le serveur est allumé et que son pare-feu laisse passer les requêtes.
  • Le serveur reste ajouté : le bot le prendra en compte dès qu'il répondra.
Rien ne s'affiche dans mon salon

Tapez /config status. Si un salon affiche « droits manquants », donnez au bot Voir le salon, Envoyer des messages et Intégrer des liens dans ce salon. Le tableau de bord se met à jour chaque minute.
